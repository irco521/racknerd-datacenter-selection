## 两个来源的排序不一样，该信谁

中文圈两篇传播较广的 RackNerd 测评，套餐价格表逐字一致，但对机房的排序完全相反：一篇写“首选洛杉矶 DC-02，备选圣何塞”，把 DC-02 称作镇店之宝；另一篇写“圣何塞 > 洛杉矶 DC-02 > 西雅图”，认为圣何塞综合表现最优。还有资料把洛杉矶描述成“先试它，错不了太多”的默认项。

这不是谁抄错了，而是三家都没有公开的、可复现的测试方法，延迟数据来自不同时间、不同城市的 ping。差距落在 20–40ms 这个量级时，很可能只是测量误差。

对你有用的结论是：**这两个机房属于同一档，不必纠结谁第一，花十分钟自己测。** 方法很简单，用上面的测试 IP，在你平时用的网络、平时上网的时间段（尤其是晚高峰）ping 一遍，同时看一下丢包率。延迟低 10ms 带来的体验差别，远小于晚高峰丢包 5% 带来的差别。

## 买完才发现选错，还能救吗

**IP 被墙**：有资料提到购买后 **72 小时内可以免费更换 IP**，超过之后换 IP 收 $3。拿到机器第一件事是测 IP 通不通，别等部署完一堆服务才发现。这条政策的具体执行以下单时的官方说明和工单回复为准。

**想换机房**：两个来源的说法相反。一份说多机房可选的套餐可以发工单申请迁移，只有 1 次机会，固定机房的套餐有网友反馈可以花 $5 迁；另一份说促销套餐不支持迁移，只能重新买一个再搬数据。这种互相矛盾的政策，最稳的做法是**下单前先开工一个工单问清楚**，把你准备买的套餐和想去的机房写进去，拿到书面答复再付款，比事后扯皮省事。

**IPv6**：全系可以提工单免费申请，有资料称最多 100 个，DC-02、DC-03、多伦多、斯特拉斯堡、都柏林等机房支持。有 IPv6 需求的话下单后开工单即可。
